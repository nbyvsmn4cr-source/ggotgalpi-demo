# 꽃갈피 지원

꽃갈피는 책과 감상을 날짜별로 기록하는 앱입니다.

## 오류나 개선 사항 문의

[GitHub 문의 게시판](https://github.com/nbyvsmn4cr-source/ggotgalpi-demo/issues)에 새 이슈를 작성해 주세요. GitHub 계정이 필요합니다. 기기 모델, iOS 버전, 앱 버전, 문제가 발생하는 순서를 알려주시면 도움이 됩니다.

**공개 게시판입니다.** 비밀번호, Apple 계정, 개인 감상문 원문 등 민감한 내용을 올리지 마세요. 스크린샷의 개인정보는 가려 주세요.

## 기록이 보이지 않을 때

휴지통과 달력의 선택 날짜를 먼저 확인해 주세요. iCloud 동기화는 동일한 Apple 계정, 네트워크 상태 및 iCloud 사용 가능 여부에 영향을 받습니다. 동기화 문제가 있을 때 앱을 삭제하거나 기기 데이터를 초기화하지 마세요.

## 삭제한 기록 복원

설정 → 휴지통에서 보관 기간 내의 감상문을 복원할 수 있습니다. 영구 삭제한 기록은 앱에서 복원할 수 없습니다.
