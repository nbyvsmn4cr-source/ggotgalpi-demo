# 꽃갈피 개인정보처리방침

최종 작성일: 2026년 10월 24일

## 기록의 저장과 사용

꽃갈피는 사용자가 입력한 책 정보, 표지, 감상문, 마음에 드는 문장, 별점과 독서 날짜를 독서 기록 기능 제공에 사용합니다. 기록은 기기에 저장됩니다. iCloud 이용이 가능한 환경에서는 책과 감상 기록이 사용자의 iCloud 비공개 데이터베이스에 동기화됩니다. iCloud는 Apple이 제공하며 Apple의 약관과 개인정보처리방침이 적용됩니다.

앱 운영자는 독서 기록을 별도의 운영자 서버로 수집하지 않습니다. 현재 앱에 광고, 이용자 추적 또는 제3자 분석 도구는 포함되어 있지 않습니다. 표시 설정과 좋아하는 작가 등 일부 환경설정은 기기에만 저장되며 동기화되지 않습니다.

## 도서 검색

사용자가 책 검색을 실행하면 검색어가 Cloudflare에서 운영되는 꽃갈피 검색 서버를 거쳐 카카오 도서 검색 API로 전달됩니다. 달력·책장 공용 검색창에서도 키보드의 ‘검색’을 누르면 입력한 검색어로 온라인 도서를 검색합니다. 입력 중인 기존 책·감상 기록 필터링은 기기에서 수행하며, 검색을 실행하기 전에는 검색어를 외부로 전송하지 않습니다. 저장된 감상문이나 별점, 기존 독서 기록을 자동으로 전송하지는 않지만, 사용자가 검색어로 입력하고 제출한 내용은 전송되므로 민감한 내용을 입력하지 않도록 주의해 주세요. 검색 요청의 과도한 반복을 제한하기 위해 Cloudflare가 제공하는 접속 IP 주소를 사용합니다. 검색 서버에서 검색어를 별도 데이터베이스에 보관하거나 요청 로그를 남기도록 설정하지 않았으나, 각 서비스 제공자는 서비스 제공 및 보안을 위해 네트워크 정보를 처리할 수 있습니다.

책 표지를 표시할 때 이미지 제공 서버로 네트워크 요청이 전송됩니다. 선택한 책의 ISBN과 표지 URL은 책 정보와 함께 기기 및 이용 가능한 iCloud에 저장됩니다. 검색은 선택 기능이며 직접 입력도 가능합니다.

## 보관과 삭제

감상문을 삭제하면 휴지통으로 이동하며, 선택한 7일·14일·30일 보관 기간이 지난 기록은 앱이 실행되거나 활성화되어 정리 작업을 수행할 때 영구 삭제됩니다. 기간 내에는 복원할 수 있습니다. 휴지통에서 영구 삭제하거나 책 자체를 삭제하면 관련 기록은 복구할 수 없습니다. 동기화된 변경 사항은 네트워크 및 iCloud 상태에 따라 다른 기기에 지연 반영될 수 있습니다. 앱을 삭제하는 것만으로 iCloud 데이터까지 삭제되지는 않을 수 있습니다.

## 문의

[꽃갈피 지원 안내](support.md)를 확인해 주세요. 공개 문의에 감상문 원문, 계정 정보 또는 개인정보를 첨부하지 마세요.

## 변경 안내

수집 항목이나 처리 방식이 달라지면 이 문서를 갱신합니다. 이 문서는 현재 구현을 기준으로 작성되었으며 실제 배포 버전과 일치하는지 출시 전에 확인해야 합니다.
