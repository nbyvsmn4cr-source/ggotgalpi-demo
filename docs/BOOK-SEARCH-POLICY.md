# 도서 검색 이용 조건 확인 — 2026-10-24

## 확인한 공식 자료

- 운영정책: https://developers.kakao.com/terms/ko/site-policies
- 도서 검색 API: https://developers.kakao.com/docs/ko/daum-search/dev-guide#search-book

운영정책 제5조 20항은 데이터 캐시의 목적과 최신 상태 유지에 제한을 둡니다.
제5조 30항에는 제공 정보의 복사·이용·타인 제공 제한이 있고, 제4조는 제3자 권리 침해를 금지합니다.
따라서 API 호출이 가능하다는 사실만으로 선택한 도서 정보의 영구 보관과 검색 화면 밖 표지 이용까지 허용되었다고 판단하지 않았습니다.
이는 현 구현이 확정적으로 금지됐다는 결론도 아닙니다. 독서 기록용 보관에 해당 조항이 어떻게 적용되는지 제공자 확인이 필요합니다.

## 현재 구현과 확인할 범위

- 사용자가 검색 후 고른 한 권의 제목·작가·출판사·ISBN·표지 URL을 기기에 저장합니다.
- 사용 가능한 경우 사용자의 iCloud로 동기화합니다. 저장 정보 자동 갱신은 구현되어 있지 않습니다.
- 검색 결과 전체를 서버 DB에 수집하지 않습니다. 감상문·별점은 검색 서버로 전송하지 않습니다.
- 표지 파일을 앱 자산으로 재배포하지 않고 제공된 HTTPS URL을 화면 표시 시 요청합니다. 이미지 로딩 과정의 시스템 캐시와 별도로 영구 이미지 저장 기능은 구현하지 않았습니다.
- 검색 결과에는 출처와 Daum 상세 링크가 있으나, 저장한 책장·달력의 각 표지에는 상세 링크가 없습니다.
- 제공자 답변에 따라 보관 기간·갱신·출처 표시·링크 구성을 조정할 수 있습니다. 기존 사용자 기록은 임의로 삭제하지 않습니다.

## 카카오 데브톡 문의 초안 (미발송)

제목: 독서 기록 앱의 도서 검색 결과 선택 저장 및 표지 표시 가능 범위 문의

안녕하세요. iOS 독서 기록 앱 '꽃갈피'를 개발 중입니다. 앱 ID는 1612950입니다.

사용자가 직접 제목 또는 ISBN을 검색하고 결과 한 권을 선택하면 제목, 작가, 출판사, ISBN, 썸네일 URL을 사용자의 기기 및 개인 iCloud에 저장하려고 합니다. 독서 기록을 계속 열람할 수 있도록 보관하며, 현재 자동 갱신이나 보관 만료는 없습니다. 사용자가 일부 책 정보를 수정할 수도 있습니다.

검색 결과 전체를 수집하는 DB는 없고, Cloudflare Worker는 API 키 보호를 위해 요청을 중계합니다. 검색 결과 화면에는 출처와 Daum 상세 페이지 링크를 제공합니다. 저장한 책의 표지는 반환된 URL에서 불러와 책장과 달력에도 표시하며, 표지 파일을 앱에 포함하여 재배포하지 않습니다.

1. 이와 같은 사용자가 선택한 책 정보의 장기 보관 및 개인 iCloud 동기화가 허용되는지요?
2. 운영정책의 캐시 최신화 조건이 이 독서 기록에도 적용되는지, 필요한 갱신 주기나 보관 기간이 있는지요?
3. 표지를 검색 결과 외의 개인 책장·달력에서 표시할 수 있는지, 표지별 출처 또는 상세 페이지 링크가 필요한지요?
4. 앱 유료 판매나 광고 도입 시 별도 승인 또는 변경할 조건이 있는지요?

허용 범위와 필요한 표기·갱신 조건을 안내 부탁드립니다. 감사합니다.

API 키나 토큰은 문의에 포함하지 않습니다. 실제 발송은 사용자 확인 후 별도로 진행합니다.
