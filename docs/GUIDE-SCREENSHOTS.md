# 사용 가이드 사진

- 2026-10-25, 사용자의 iPhone 17 Pro / iOS 26.5 시뮬레이터에서 실제 화면을 촬영했습니다.
- 사용자가 작성한 책·감상문·날짜를 포함합니다. 사용자는 이 사진을 앱 사용자에게 공개하고 이후 GitHub 저장소에 포함하는 데 명시적으로 동의했습니다. 기록은 수정하지 않고 촬영했습니다.
- `GuideCalendar`, `GuideSearch`, `GuideEntry`, `GuideSettings` 이미지 세트에는 각각 밝은 모드와 다크모드 원본 PNG가 있습니다. 화면 모드에 따라 자동 선택합니다.
- 가이드는 사진 위에 강조 테두리와 설명 말풍선을 겹쳐 보여주는 10단계 안내입니다. 이전·다음 버튼으로 이동하며 첫 실행과 설정의 다시 보기는 같은 뷰를 사용합니다.
- 강조 영역 좌표는 원본 이미지 크기에 대한 비율로 저장합니다. 사진 교체 시 해당 좌표도 함께 확인해야 합니다.
- 기존 예시 데이터 사진은 사용자 기록 사진으로 교체했습니다. 사진은 정적인 안내 자료이며 앱 실행 시 사용자 데이터를 주입하지 않습니다.
- 관련 화면의 디자인·기능 변경 시 두 모드의 사진을 함께 다시 촬영해야 합니다.
