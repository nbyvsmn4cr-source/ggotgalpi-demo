# 도서 검색 검증 (2026-10-24)

## 확인 완료

- Cloudflare 운영 서버: 제목 검색 및 ISBN 검색 HTTP 200.
- 서버 자동 테스트 11개 통과: 잘못된 입력, 미설정, 호출 제한, 응답 필드 필터링, 오류 비밀정보 차단. 추가로 IP 누락·제한 기능 장애, 제공자 429 응답, 한글 검색·페이지 전달, 리디렉션 차단, 잘못된 JSON, 반환 개수·안전한 URL 처리를 확인했습니다. 실제 운영 서버 과부하를 유발하지 않는 모의 응답 테스트입니다.
- SwiftUI 시뮬레이터 최종 빌드 성공.
- 독립 SwiftData 저장소 회귀 검증: ISBN·표지 URL 재로드, 감상 기록·별점·휴지통·복원 등.
- iPhone Duo / iOS 27.1 UI: 책장 → 새 책 등록 → 검색 → ISBN 9788996991342 입력.
- 실제 검색 결과의 제목·작가·출판사·표지 표시 확인.
- 결과 선택 후 입력 폼에 제목·작가·출판사 및 표지 자동 입력 확인.
- 저장 후 책장 표시 및 앱 종료/재실행 후 책 유지 확인.
- 실제 표지 표시 시 기존 구분 색상이 양옆에 비치는 문제 수정 후 재빌드·화면 확인.
- Duo 달력: 10월 20일 → 새 책 검색·선택·저장 → 감상 작성 자동 전환, 날짜 10월 20일 유지.
- 해당 날짜에 테스트 감상 `12345` 저장 후 당일 목록에 즉시 반영 확인.
- 결과 없는 검색어의 안내 표시 및 ISBN으로 재검색 성공.
- iPhone SE 2 / iOS 26.5: 새 책 검색 화면, 제목 `1984` 검색, 결과 표지·제목 표시, 스크롤 및 ‘더 보기’ 후 추가 결과 표시 확인. 새 책 추가는 취소하여 기존 데이터 유지.

테스트용 Duo 시뮬레이터에 ‘미움받을 용기’ 총 2권과 10월 20일 테스트 감상 1개를 추가했고 삭제하지 않았습니다.
기존 iPhone 17 Pro의 사용자 기록은 수정하지 않았습니다.

## 아직 별도 확인 필요

- 오프라인·호출 한도 오류의 UI 수동 검증.
- iOS 17 실행 및 소프트웨어 키보드 표시 상태의 작은 화면 검증(이번 입력은 하드웨어 키보드 전달 사용).
- 실기기 간 iCloud 동기화, 도서 API 데이터 보관·표지 이용 조건 및 개인정보처리방침 공개.
- 카카오 공식 운영정책 확인 결과와 문의 초안: `docs/BOOK-SEARCH-POLICY.md`. 현재 구현의 장기 보관 방식에 대한 허용 여부는 확인되지 않았습니다.

위의 미검증 항목까지 완료되었다거나 출시 준비가 전부 끝났다는 의미는 아닙니다.

## 공용 검색 확장 (2026-10-24)

- 달력·책장의 공용 검색 및 별도 통합 검색 화면에서 명시적으로 검색을 제출하면 온라인 도서 결과를 표시하도록 연결했습니다. 입력 중에는 기존 로컬 필터링만 수행합니다.
- 온라인 결과 선택 시 책 추가 폼을 자동 입력하고, ISBN이 이미 등록된 책과 겹치면 기존 책 상세를 엽니다. 추가 폼을 취소하면 저장하지 않습니다.
- 검색어 변경 시 온라인 결과를 제거하고 요청을 취소합니다. 페이지 추가·재시도·빈 결과·오류 안내와 결과 ID 중복 제거를 포함합니다.
- ISBN을 기존 책 로컬 검색 항목에도 추가했습니다. 개인정보처리방침 초안에 공용 검색어의 전송 시점을 반영했습니다.
- 동일 변경 소스를 검증용 로컬 복사본에 반영하여 시뮬레이터 Debug 빌드 성공. 이번 공용 검색 흐름의 직접 UI 조작 검증은 아직 하지 않았습니다.
- 온라인 결과에서 책 추가 후 감상문 작성으로 연결합니다. 감상문 저장 성공을 알리는 콜백을 추가했고, 작성 시트가 닫힌 뒤 검색을 시작했던 달력 또는 책장의 검색 상태를 초기화하도록 연결했습니다. 취소·저장 실패에는 메인 복귀 콜백을 호출하지 않습니다. 날짜별 달력의 기존 작성 흐름은 유지합니다.
